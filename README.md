# Polyfill

[Demo](https://jlongyam.github.io/polyfill/)

## Node

```
npm install @jlongyam/polyfill
```

```js
"use strict"
require("@jlongyam/polyfill");
```

see example: `check.cjs`

## Browser

1. include `polyfill.js` in head
2. change `polyfill.path`
3. see example: `check.html`

## Load

Add/Remove manually.
